# Portafolio - Andres Galeano

Portafolio personal de Andres Galeano, Ingeniero de Sistemas especializado en Backend Development y Análisis de Datos.

## Estructura del Proyecto

```
Blog/
├── assets/                    # Recursos multimedia
│   ├── favicon.svg           # Favicon del sitio
│   └── CV_Andres_Galeano.pdf # Currículum descargable
├── css/                      # Hojas de estilo
│   ├── base.css             # Estilos base y reset
│   ├── hero.css             # Sección hero y navegación
│   └── sections.css        # Secciones: sobre mí, proyectos, artículos, footer
├── js/                       # Scripts de JavaScript
│   ├── main.js              # Inicializador principal
│   ├── typewriter.js        # Efecto de máquina de escribir
│   ├── card-3d.js          # Efecto 3D en tarjetas
│   └── click-effect.js     # Efecto visual en clicks
├── index.html               # Página principal
└── README.md               # Documentación
```

## Tecnologías

- HTML5
- CSS3 (Grid, Flexbox, Animaciones)
- JavaScript (ES6+ Modules)
- Google Fonts (Poppins)

## Características

- Diseño responsive
- Modo oscuro
- Efectos visuales interactivos
- SEO optimizado
- Descarga de CV
- Navegación suave
